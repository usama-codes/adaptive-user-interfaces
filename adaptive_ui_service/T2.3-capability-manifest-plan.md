### Pydantic model and loader

#### [NEW] [capability.py](file:///home/iosamaayaz/Coding/FYP Stuff/openproject-private-clean/adaptive_ui_service/app/models/capability.py)

```python
from __future__ import annotations

import json
from pathlib import Path
from typing import Any

from pydantic import BaseModel, field_validator


MANIFEST_PATH = Path(__file__).parents[2] / "data" / "capability_manifest.json"


class Capability(BaseModel):
    capability_id: str
    name: str
    description: str
    category: str
    required_permissions: list[str]
    ui_change: dict[str, Any]

    @field_validator("capability_id")
    @classmethod
    def id_must_be_non_empty(cls, v: str) -> str:
        if not v.strip():
            raise ValueError("capability_id must not be empty")
        return v


def load_manifest(path: Path = MANIFEST_PATH) -> list[Capability]:
    raw = json.loads(path.read_text(encoding="utf-8"))
    capabilities = [Capability.model_validate(entry) for entry in raw]
    _assert_unique_ids(capabilities)
    return capabilities


def _assert_unique_ids(capabilities: list[Capability]) -> None:
    ids = [c.capability_id for c in capabilities]
    if len(ids) != len(set(ids)):
        seen: set[str] = set()
        for cap_id in ids:
            if cap_id in seen:
                raise ValueError(f"Duplicate capability_id: {cap_id!r}")
            seen.add(cap_id)
```

**Design decisions:**

| Decision | Rationale |
|---|---|
| `MANIFEST_PATH` resolved relative to the module file | Works regardless of where `uvicorn` is launched from |
| `load_manifest(path=...)` accepts a `Path` override | Makes tests trivially injectable without monkeypatching |
| Unique-id check in the loader, not the model | A single entry can't know about its siblings; the loader has the full list |
| `dict[str, Any]` for `ui_change` | Defers schema to T3.1 (`schemas/diff.json`); no premature constraint |

The loader is **not** registered as a FastAPI startup hook here — that belongs in `app/main.py` and is out of scope for this ticket.

    Call load_manifest() with the real manifest file
    Assert len(result) >= 20
    Assert all items are Capability instances

test_missing_field_fails_validation
    Pass a fixture dict missing "description"
    Assert Pydantic ValidationError is raised

test_duplicate_ids_fail_validation
    Pass a fixture with two entries sharing the same capability_id
    Assert ValueError is raised with a message containing the duplicate id

test_ids_are_unique
    Call load_manifest() and assert len(ids) == len(set(ids))
    Covered by the loader itself, but explicit test makes the DoD unambiguous
