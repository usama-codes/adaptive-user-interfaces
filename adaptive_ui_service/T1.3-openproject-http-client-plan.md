### Exception Classes

#### [NEW] [exceptions.py](file:///home/iosamaayaz/Coding/FYP Stuff/openproject-private-clean/adaptive_ui_service/app/core/exceptions.py)

Define two exception classes needed by the client:

```python
class OpenProjectAuthError(Exception):
    """Raised when the OpenProject API returns HTTP 401 (unauthorized)."""

class OpenProjectAPIError(Exception):
    """Raised for non-auth OpenProject API errors."""

    def __init__(self, status_code: int, response_body: str, message: str = ""):
        self.status_code = status_code
        self.response_body = response_body
        super().__init__(message or f"OpenProject API error {status_code}: {response_body}")
```

**Design decisions:**
- `OpenProjectAuthError` is kept simple (no status code needed — it's always 401)
- `OpenProjectAPIError` carries `status_code` and `response_body` as attributes so callers (and the future global error handler in T1.8) can inspect and log them
- Both inherit from `Exception` (not `HTTPException`) — the mapping to HTTP response codes belongs in the T1.8 global handler, keeping the client layer framework-agnostic

### HTTP Client

#### [NEW] [openproject_client.py](file:///home/iosamaayaz/Coding/FYP Stuff/openproject-private-clean/adaptive_ui_service/app/core/openproject_client.py)

The main deliverable. An `OpenProjectClient` class wrapping `httpx.AsyncClient`:

```python
import asyncio
import httpx
from adaptive_ui_service.app.core.config import settings
from adaptive_ui_service.app.core.exceptions import OpenProjectAuthError, OpenProjectAPIError

class OpenProjectClient:
    def __init__(
        self,
        base_url: str | None = None,
        api_token: str | None = None,
        timeout: float = 10.0,
        max_retries: int = 2,
    ):
        self._base_url = (base_url or settings.openproject_url).rstrip("/")
        self._api_token = api_token or settings.openproject_api_token
        self._timeout = timeout
        self._max_retries = max_retries
        self._client = httpx.AsyncClient(
            base_url=self._base_url,
            headers={"Authorization": f"Token {self._api_token}"},
            timeout=httpx.Timeout(self._timeout),
        )

    async def get(self, path: str, params: dict | None = None) -> dict:
        return await self._request("GET", path, params=params)

    async def post(self, path: str, body: dict) -> dict:
        return await self._request("POST", path, json=body)

    async def _request(self, method: str, path: str, **kwargs) -> dict:
        last_exception: Exception | None = None
        for attempt in range(self._max_retries + 1):
            try:
                response = await self._client.request(method, path, **kwargs)
            except httpx.TimeoutException as exc:
                raise OpenProjectAPIError(
                    status_code=0,
                    response_body="",
                    message=f"Request to {path} timed out after {self._timeout}s",
                ) from exc

            if response.status_code == 401:
                raise OpenProjectAuthError(
                    f"Authentication failed for {path}"
                )

            if response.status_code >= 500:
                last_exception = OpenProjectAPIError(
                    status_code=response.status_code,
                    response_body=response.text,
                )
                if attempt < self._max_retries:
                    await asyncio.sleep(2 ** attempt)  # 1s, 2s
                    continue
                raise last_exception

            if response.status_code >= 400:
                raise OpenProjectAPIError(
                    status_code=response.status_code,
                    response_body=response.text,
                )

            return response.json()

        raise last_exception  # unreachable but satisfies type checker

    async def close(self) -> None:
        await self._client.aclose()
```

**Key design decisions:**

| Decision | Rationale |
|---|---|
| Constructor accepts optional `base_url` / `api_token` overrides | Makes testing straightforward — tests pass explicit values instead of depending on env vars |
| Single `_request` method handles retry loop | DRY — `get` and `post` are thin wrappers |
| `asyncio.sleep(2 ** attempt)` for backoff | `2^0 = 1s`, `2^1 = 2s` — matches the spec exactly |
| No retry on 401 | Auth errors won't resolve by retrying |
| No retry on 4xx (non-401) | Client errors are not transient |
| Timeout raises `OpenProjectAPIError` with `status_code=0` | Keeps a single exception hierarchy; the zero status code distinguishes timeouts from HTTP errors |
| `close()` method exposed | Callers (and the FastAPI lifespan) can clean up the underlying connection pool |
